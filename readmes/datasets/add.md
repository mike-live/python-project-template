# Добавить свой датасет

Текущий пайплайн рассчитан на регрессию с числовыми признаками без
пропусков и бесконечных значений. Целевая колонка должна быть числовой.
Другая структура требует соответствующей предобработки.

1. Поместите CSV с разделителем-запятой в `PROJECT_DATA_DIR/01_raw/`,
   например `houses.csv`.
2. Добавьте профиль в существующий словарь `datasets` в
   [globals.yml](../../conf/base/globals.yml):

```yaml
datasets:
  # Существующие boston и diabetes остаются здесь.
  houses:
    target_col: price
```

Имя профиля совпадает с именем файла без `.csv`.
`price` — пример: укажите реальную целевую колонку.

3. Запустите:

```bash
uv run kedro run --params='dataset_name=houses,mlflow_run_name=houses-baseline'
```

Каталог и пайплайн остаются общими. Наличие пропусков или категориальных
значений не исправляется автоматически при добавлении профиля.
Сырые данные сохраняйте исходными; необходимую обработку добавляйте в nodes.

Далее: [настроить node](../kedro/pipeline.md) · [найти результаты](outputs.md).
