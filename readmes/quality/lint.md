# Проверить и отформатировать код

Запустите проверку из корня проекта:

```bash
uv run ruff check .
```

При отсутствии нарушений Ruff завершится успешно.
Для автоматического исправления доступных нарушений:

```bash
uv run ruff check . --fix
```

Исправления меняют исходные файлы. Проверьте diff перед коммитом.
Не все нарушения исправляются автоматически.

Форматирование выполняется отдельной командой:

```bash
uv run ruff format .
```

Для проверки форматирования без изменения файлов:

```bash
uv run ruff format . --check
```

В проекте `notebooks` исключены настройкой Ruff.
После правок повторите lint и [тесты](tests.md).
