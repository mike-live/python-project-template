# Настроить правила Ruff

Настройки находятся в [pyproject.toml](../../pyproject.toml).

| Группа | Назначение |
| --- | --- |
| E, W | Проверки стиля pycodestyle |
| F | Неиспользуемые импорты, неопределённые имена и другие проверки Pyflakes |
| UP | Обновление устаревших конструкций Python |
| S | Проверки flake8-bandit |

`select` задаёт набор правил, `extend-select` дополняет выбранный набор.
В проекте используется `extend-select`. Каталог правил:
[официальный справочник](https://docs.astral.sh/ruff/rules/).

## Сделать точечное исключение

Для одной строки укажите конкретный код:

```python
import os  # noqa: F401
```

Это пример намеренно неиспользуемого импорта, а не рекомендация
сохранять такие импорты без причины.

Для файлов используется `per-file-ignores`. В проекте разрешены
обычные assert в тестах:

```toml
[tool.ruff.lint.per-file-ignores]
"tests/**/*.py" = ["S101"]
```

`ignore` отключает правила для проекта, а `exclude` исключает пути
из обычного обхода файлов. Изменения этих настроек распространяются
на последующие проверки.
